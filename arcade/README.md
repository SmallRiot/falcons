# Ледовый дроп

Локальная однопользовательская песочница на Node 24. Хранилище SQLite создаётся в `.local/` рядом с модулем. Запуск из каталога arcade:

```sh
node server.mjs
```

Открыть http://127.0.0.1:5192. Начислить очко в другом терминале и обновить страницу:

```sh
node server.mjs goal match-01-goal-01
```

Каждый ID гола засчитывается один раз. В браузере можно только запустить до 100 шайб по одному очку за штуку или купить коллекционный предмет. Тестовая валюта и трофеи виртуальные. Сервер принимает соединения только через loopback. Все локальные клиенты работают с одним кошельком. Переменные ARCADE_DATA и ARCADE_PORT позволяют изолировать тестовые экземпляры.

Перед броском сервер сообщает SHA-256 от текстового hex-секрета. После получения случайного 16-байтового nonce браузера сервер раскрывает секрет и публикует квитанцию. Путь — старшие 16 бит HMAC-SHA256 (ключ — UTF-8 hex-строка секрета, сообщение — nonce:индекс, индексы шайб начинаются с нуля). Количество единиц определяет ячейку. Баланс, квитанция и следующий секрет фиксируются одной транзакцией. Повтор того же запроса возвращает прежнюю квитанцию. Сохранённое до броска обязательство можно сравнить с commitment в квитанции.

Из 65 536 равновероятных путей два приводят к выплате 1000×. Средний возврат — 97,0233%. Дробные выплаты хранятся целыми единицами по 0,2 очка. Для проверки используется `node --test store.test.mjs`.

В мини-приложении вход спрятан на правом краю главной игрока. API берёт ID из авторизованной сессии. Кошелёк каждого игрока хранится в DATA_DIR/arcade/<ID>/game.sqlite. Начисление за гол внутри рабочего контейнера:

```sh
ARCADE_DATA=/data/arcade/12345 node arcade/server.mjs goal game-42-goal-3
```

Подставьте ID игрока и уникальный ID гола. При повторе той же команды баланс не удвоится.
